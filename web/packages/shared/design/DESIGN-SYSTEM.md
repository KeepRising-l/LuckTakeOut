# LuckTakeOut 设计规范系统（Design System）

> 主题：**烟火食味 Warm Kitchen**
> 令牌真源：`web/packages/shared/design/tokens.css`（唯一允许修改色值/字号/圆角的地方）
> Vant 换肤映射：`web/packages/shared/design/vant-theme.css`
> 本文档是规范说明；一切以令牌文件为准，两者冲突时改令牌、同步文档。

---

## 1. 设计原则

1. **暖、有食欲**：全站以暖米白为画布、食味橙为主色，像一张铺上桌的牛皮纸；价格、主操作用暖橙直接刺激点餐欲望。
2. **一张卡片一件事**：内容全部装进白色圆角卡片，卡片之间靠间距分层，不靠阴影堆叠。
3. **克制的强调**：每屏只允许一个最亮的橙色（主按钮 / 当前价格），其余为文字层级与发丝线。
4. **餐饮语义色固定**：葱绿=新鲜/成功，麦芽金=促销，番茄红=待支付/取消，靛蓝=配送中。全局不允许同一色值表达两种业务含义。
5. **三端一套语言**：顾客 H5、商户端、骑手端共用同一套令牌，商户/骑手端是同一设计系统的桌面端与作业端变体。

| 令牌 | 值 | 用途 |

| `--surface` | `#ffffff` | 卡片、弹层、导航栏 |
| `--surface-2` | `#f7f0e4` | 输入框底、次级填充、标签底 |
| `--surface-3` | `#f1e7d6` | 选中态、Tabbar 激活胶囊底 |
| `--ink-1` | `#322820` | 主文字、标题（对白底 11.6:1） |

## 3. 字体排印

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font-sans` | PingFang SC / Microsoft YaHei 系统栈 | 正文、界面默认 |
| `--font-serif` | Noto Serif SC / 宋体栈 | **品牌衬线**：登录页标题、店铺名、「我的」昵称等门面大字 |

| 字号令牌 | 值 | 典型用途 |
| --- | --- | --- |
| `--text-xs` | 11px | 角标、Tabbar 文字 |
| `--text-sm` | 12px | 辅助说明、标签 |
| `--text-md` | 13px | 次级正文、列表摘要 |
| `--text-lg` | 14px | 正文 |
| `--text-xl` | 16px | 卡片标题、导航标题 |
| `--text-2xl` | 18px | 店铺名、区块大标题 |
| `--text-3xl` | 22px | 页面主标题、支付大金额 |
| `--text-4xl` | 28px | 登录页 Hero 标题 |

规则：
- 价格一律 `font-variant-numeric: tabular-nums` + 700 字重，¥ 符号比数字小一号。
- 品牌衬线仅用于「品牌感」文字，一屏不超过一处；地址、电话等数据信息一律 sans。
- 行高：正文 1.5；多行摘要 1.4。

## 4. 间距 / 圆角 / 阴影

**间距**：`--space-1~8` = 4/8/12/16/20/24/32px；页面左右边距统一 `--gutter: 12px`（桌面端用 `--space-4`）。
**卡片内边距**：移动端 12px，桌面端 16px。

**圆角**：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 8px | 小标签、缩略图、输入框内元素 |
| `--radius-md` | 12px | 按钮（非胶囊场景）、输入框 |
| `--radius-lg` | 16px | **默认卡片**、cell-group |
| `--radius-xl` | 20px | 底部弹层、Hero 卡 |
| `--radius-pill` | 999px | 主按钮、筛选芯片、Tabbar |

**阴影**（暖橙棕染色，禁止纯黑投影）：

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--shadow-1` | `0 1px 2px rgba(122,66,18,.05)` | 卡片默认 |
| `--shadow-2` | `0 4px 14px rgba(122,66,18,.08)` | 悬浮卡、底部栏 |
| `--shadow-3` | `0 10px 30px rgba(122,66,18,.12)` | 弹层 |
| `--shadow-brand` | `0 6px 16px rgba(255,111,28,.3)` | 主按钮光晕 |

## 5. 图标规范

- 风格：线性、stroke 1.7、圆角端点、`currentColor`，规格 24×24。
- 顾客端分类入口（美食/奶茶/快餐/烧烤/水果/甜品/早餐/夜宵）**不使用 emoji**，使用 `components/FoodIcon.vue` 内联 SVG：碗面、奶茶杯、汉堡、烤串、西瓜、蛋糕、煎蛋、月亮。每个图标置于 44×44 暖色圆形底（`--brand-50` 系），图标色 `--brand-600`。
- 其余场景使用 Vant 自带线性图标（`-o` 系列），通过 `--van-*` 变量换色，不在业务代码写色值。

## 6. 动效规范

| 令牌 | 值 |
| --- | --- |
| `--ease-spring` | `cubic-bezier(.2,.8,.25,1)` |
| `--dur-fast` | 0.16s（按压、变色） |
| `--dur-base` | 0.24s（滑入、展开） |
| `--dur-slow` | 0.4s（页面级渐显） |

- 按压反馈：所有可点元素 `:active { transform: scale(.97) }`，`--dur-fast`。
- 进场：列表卡片依次渐显，`opacity 0→1 + translateY 6px`，间隔 0.05s。
- 弹层：底部上滑 `--dur-base`，背景遮罩 `rgba(50,40,32,.4)`。
- **禁止**：超过 0.5s 的动画、无限循环动画、扫光特效。

## 7. 组件规范

### 7.1 按钮（Vant van-button）

| 类型 | 样式 |
| --- | --- |
| 主按钮 Primary | 食味橙渐变 `135deg, #ff8a3d→#ff6f1c`、胶囊、白字、`--shadow-brand`；height 46px（large）/ 38px（normal） |
| 次按钮 Default | 白底 + `--hairline-strong` 描边、`--ink-1` 字 |
| 危险 Danger | 番茄红实底 |
| 成功 Success | 葱绿实底 |
| 文字链 | `--brand-600`，无底无框 |

- 每屏主按钮不超过 1 个；其余操作降级为 plain / 小尺寸。
- 尺寸：主 CTA 用 `round size="large"`；列表内操作用 `small round`。

### 7.2 卡片

- 统一：白底、`--radius-lg`、1px `--hairline` 描边、`--shadow-1`，卡片间距 `--space-3`（移动端）。
- 卡片标题：`--text-xl` 600 字重 `--ink-1`，左侧可加 4×16 品牌色竖条（仅用于「区块标题」型卡片）。
- 禁止卡片内再套同色卡片（用 `--surface-2` 平铺区分）。

### 7.3 列表项 / 商品行

- 商品图：移动端 76×76，`--radius-sm`，加载态 `--surface-2`。
- 名称 14px/500；描述 12px `--ink-3` 单行截断。
- 价格：`--brand-600`、16~18px、700 字重，¥ 小 4px。
- 步进器：圆形 + 按钮 `--brand-500`，步进输入区 `--surface-2`。

### 7.4 表单

- 输入框：`--surface-2` 底或无边框下划线两种模式；聚焦描边 `--brand-300`。
- 标签（van-tag）：圆角 6px，浅彩底 + 同色深字；促销用麦芽金，缺货/取消用番茄红。
- 校验提示用 Vant 默认红，禁止自定义其他红。

### 7.5 导航

- **顾客端 TabBar**：白底毛玻璃 + 顶部发丝线；选中项图标与文字 `--brand-600`，未选 `--ink-3`；角标 `--color-tomato`。
- **页面导航栏**：白底、48px、标题 16px `--ink-1`。
- **商户端侧边栏**：白底；菜单选中 = 橙字 + `--brand-50` 底 + 左侧 3px 品牌条；品牌区用衬线字标 + 橙点。
- **筛选芯片**：胶囊，选中 = `--brand-50` 底 + `--brand-700` 字 + `--brand-200` 描边。

### 7.6 状态与反馈

- 订单状态色固定：待支付=番茄红，待接单=麦芽金，配送中=靛蓝，已完成=葱绿，已取消=ink-3。
- 空态（van-empty）：插画 + 13px `--ink-3` 描述 + 主按钮引导操作。
- Toast/弹窗用 Vant 默认即可，禁止自定义配色。

## 8. 三端映射

| 端 | 画布 | 主色用法 | 特有约定 |
| --- | --- | --- | --- |
| 顾客 H5 | `--canvas` | 主按钮渐变、价格、TabBar 激活 | 顶部 Hero 用暖橙渐变（登录页/个人中心）；分类入口 8 个暖色圆 |
| 商户端 | `--canvas` | `--el-color-primary` 全套映射、图表主色 | Element Plus 通过 CSS 变量换肤；统计卡数字用衬线感粗体 |
| 骑手端 | `--canvas` | 与顾客端一致 | 顶部信息卡用暖橙渐变；任务卡取送信息用靛蓝图标 |

## 9. Do & Don't

| ✅ Do | ❌ Don't |
| --- | --- |
| 样式一律引用令牌变量 | 写死 `#ff6d1f` / `#1989fa` / `#f7f8fa` |
| 一屏一个橙色焦点 | 大面积高饱和平铺橙色 |
| 价格用 `--brand-600` | 价格用绿/蓝/黑 |
| 卡片间距分层 | 卡片阴影套卡片 |
| emoji 只出现在用户内容里 | emoji 当图标用 |
| 语义色按状态表使用 | 同一颜色两种含义 |

---

## 10. 变更流程

1. 新增/修改令牌 → 只改 `tokens.css`，本文件同步更新一行。
2. 新增组件 → 先查本文档是否已有对应规范；没有则补充后落地。
3. 上线前自检：全项目 grep `#ff6d1f|#1989fa|#f7f8fa` 应为 0 命中（历史文档除外）。
